# Contributing

Keep this vault useful by treating every note as an operational artifact, not a bookmark dump.

1. Start from the closest file in `templates/`.
2. Write one clear decision, pattern, runbook, or evaluation per note.
3. Link the note from at least one map in `01-Maps/`.
4. Record the evidence date in `reviewed` and choose an honest `status`.
5. Run `npm run verify` before opening a pull request.

Do not commit credentials, customer identifiers, production URLs, raw incident transcripts, personal notes, Obsidian workspace state, or third-party plugin data. Use synthetic examples and sanitized evidence.
